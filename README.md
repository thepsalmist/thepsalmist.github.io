# xodhiambo.com

Source for my personal portfolio site at [xodhiambo.com](https://xodhiambo.com).

Built with plain HTML/CSS and served with GitHub Pages/Jekyll.

## Resume link

The resume button URL is configured in `_config.yml`:

```yaml
resume_url: "https://drive.google.com/file/d/13nsZvY0eW5Yn6LGouxMkdbXhVlqaxR-0/view?usp=sharing"
```

## Local development

Install Jekyll, then run:

```sh
jekyll serve
```

The site is served locally at `http://localhost:4000` by default.
