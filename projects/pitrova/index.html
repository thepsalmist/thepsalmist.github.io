What it is

Kenyan car owners log a fill-up or a service in under a minute. Pitrova adds it up: monthly spend, cost per kilometre, fuel economy from full tank to full tank, and the services and bills coming next.

Shape

A modular monolith in three processes. The browser only talks to the web app, which forwards /api/v1 to the API, so the browser sees a single origin.

browser -> Cloudflare -> Dokku nginx -> web  Next.js 16 · PWA
                                        |  /api/v1 forwarded
                                        v
Redis 7 <------------------------------ api  FastAPI -> R2 receipts, photos
sessions · cache · rate limits          |  defer job
                                        v
                                    Postgres 16 <-- worker  Procrastinate
                                    data + job queue
                                        |  nightly dump
                                        v
                                    R2 backups  own bucket, own keys

api, worker -- OpenTelemetry over OTLP/HTTP --> Alloy

Deploy

git push dokku main. The release phase creates the job schema and runs Alembic before the worker and API restart, so new code never meets an old schema.

# apps/api/Procfile
web:     uvicorn milemind.api.app:create_app --factory --no-proxy-headers …
worker:  python -m milemind.jobs.worker
release: python -m milemind.jobs.schema && alembic upgrade head
